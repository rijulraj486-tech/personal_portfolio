# Rijul Raj — Developer Portfolio

A professional portfolio foundation for Rijul Raj, a software developer interested in web development, AI/ML, research projects, and full-stack development.

## Technology

- Next.js (App Router), React, and TypeScript
- Redux Toolkit and React-Redux
- TanStack Query, prepared for REST API integrations
- CSS with Tailwind CSS available for utility use

## Current scope

The initial foundation includes the global layout, responsive navigation and footer, SEO metadata, page routes, and the state/data architecture. Content-rich project, experience, and contact features are intentionally not implemented yet.

## Development

Requires Node.js 20.9 or later.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Run `npm run lint` before committing, and `npm run build` to make a production build.
